# Superstore Profitability Analysis 

## Project Overview
The goal of this project is to analyze the profitability of a retail Superstore. Despite high sales volume, the company's profit margins remain stagnant. This project utilizes **Python** for data cleaning and exploratory data analysis (EDA), and **Power BI** for building an interactive, actionable executive dashboard.

## Tech Stack
* **Python:** Data manipulation, Aggregations, Correlation Matrix (Pandas, Seaborn, Matplotlib).
* **Power BI:** Interactive Dashboard, DAX Measures, Conditional Formatting.

## Files in this Repository
* `superstore_analysis.ipynb`: The Jupyter Notebook containing the full EDA and data storytelling.
* `superstore dashboard.pbix`: The interactive Power BI dashboard file.
* `superstore_dashboard.pdf`: A PDF file of the final dashboard.
* `SampleSuperstore.csv`: The raw dataset used for the analysis.

## Key Business Insights
1. **Discount Strategy:** Discounts >20% severely harm the profit margin, dropping it to -77%. A strict 20% discount cap is recommended.
2. **Product Mix:** The Furniture category underperforms (2.48% margin), with Tables and Bookcases operating at a loss.
3. **Geographic Issues:** Texas, Ohio, and Pennsylvania are the most unprofitable states, requiring immediate operational review.
4. **Customer Targeting:** B2B segments (Corporate, Home Office) yield significantly higher margins than regular consumers.
